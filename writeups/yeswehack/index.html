YesWeHack Writeups

Five challenges from the YesWeHack CTF series — DOM XSS techniques, prototype pollution, and WAF bypass tricks, each broken down step by step.

DOM XSS
    DOM XSS #3
    Newline-Escaping the Blacklist

    A trailing backslash in one field merges two script lines into a single statement, slipping past a strict character blacklist with neither angle brackets nor quotes.
    DOM XSS #5
    Breaking a One-Pass Regex

    Same script-injection shape as #3, but the blacklist is a regex that only checks once — two forbidden characters slip past it cleanly.
    DOM XSS #7
    Walking Around the WAF

    A homebrew sanitiser misclassifies a prototype-tampered payload, so a classic <img onerror> sails straight to document.write.
    DOM XSS #12
    Leaking Through Prototype Getters

    A closure-locked class keeps its flag on this. Hijacking CustomEvent.prototype.detail turns a property read into an exfiltration primitive.
Prototype Pollution
    Prototype Pollution #13
    Polluting via constructor.prototype

    When __proto__ is blocked by an underscore filter and the input must stay valid JSON, constructor.prototype still routes writes straight onto Object.prototype.
